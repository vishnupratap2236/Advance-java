# Advanced Java Programming Lab

**Author:** Vishnu Pratap

A collection of Java lab exercises covering GUI development, networking, database connectivity, distributed applications, and web deployment.

## 📂 Projects & Experiments

| No. | Experiment | Technologies |
|---|---|---|
| 1 | Student Registration Form | Java Swing, AWT |
| 2 | Calculator using MVC | Java Swing, MVC |
| 3 | Client-Server Communication | TCP Sockets |
| 4 | Database Operations | JDBC, MySQL |
| 5 | Remote Method Invocation | Java RMI |
| 6 | Web Server Deployment | Apache Tomcat |
| 7 | ShopSphere E-commerce | Java, JSP, Servlets, MySQL |

## 🛠️ Requirements

- JDK 17 or later
- MySQL 8.0+
- Apache Maven 3.8+
- Apache Tomcat (as required by the project)

Check your installations:

```bash
java -version
javac -version
mvn -version
mysql --version
```

## 🚀 Getting Started

Clone the repository and enter the project directory:

```bash
git clone <your-repository-url>
cd <repository-folder>
```

Open the relevant experiment folder and follow its compilation and execution instructions.

For database-based applications, configure your MySQL database credentials before running the program.

## 🛍️ ShopSphere

ShopSphere is an e-commerce application included in this repository. It demonstrates web application development using Java technologies and database integration.

Refer to the `ShopSphere/` directory for its source code and project-specific setup instructions.

## 📚 Learning Objectives

- Develop Java desktop applications.
- Understand MVC architecture and event handling.
- Implement network communication and RMI.
- Connect Java applications to MySQL.
- Deploy Java web applications using Tomcat.
